\# QA E-Commerce Automation Framework



\## Overview



Hybrid Automation Framework developed using:



\* Playwright

\* TypeScript

\* Cucumber BDD

\* Maven

\* TestNG

\* Rest Assured

\* PostgreSQL

\* JDBC

\* Jenkins



\## Framework Components



\### UI Automation



\* Playwright

\* TypeScript

\* Cucumber BDD

\* Page Object Model



\### API Automation



\* Rest Assured

\* TestNG

\* Maven



\### Database Automation



\* PostgreSQL

\* JDBC



\### CI/CD



\* Jenkins Pipeline



\## Project Structure



qa-ecommerce-automation



├── ui-automation
