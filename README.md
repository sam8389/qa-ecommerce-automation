\# QA E-Commerce Automation Framework



\## Overview



End-to-end QA Automation Framework built using modern automation technologies covering:



\* UI Automation

\* API Automation

\* Database Validation

\* CI/CD Integration



\## Tech Stack



\### UI Automation



\* Playwright

\* TypeScript

\* Cucumber BDD

\* Page Object Model (POM)



\### API Automation



\* Rest Assured

\* Maven

\* TestNG



\### Database Automation



\* PostgreSQL

\* JDBC



\### CI/CD



\* Jenkins Pipeline

\* Git



\## Project Structure
